# Kakao Login — Console Submission

Values come from `form-filled.md`. Exact redirect URI comes from
`callbacks.md`, generated by `pnpm oauth:approval:report`.

Console: <https://developers.kakao.com/console/app>

## Phase 1 — Application

- [ ] Create or open app `The Hideaway`.
- [ ] Set Korean display name to `하이드어웨이`.
- [ ] Set business/service URL to `https://hideawayseoul.com`.
- [ ] Add platform type `Web`.
- [ ] Add site domain:

```text
https://hideawayseoul.com
```

## Phase 2 — Kakao Login

Path: **Product Settings -> Kakao Login**

- [ ] Enable Kakao Login.
- [ ] Add Redirect URI from the Kakao row in `callbacks.md`.

Expected production shape:

```text
https://hideawayseoul.com/api/auth/oauth2/callback/kakao
```

Consent items:

- [ ] `profile_nickname` — required, used as display name.
- [ ] `account_email` — required, used as account identifier.

Do not request profile image, phone number, birthday, gender, age range, address,
or shipping consent in this approval round.

## Phase 3 — Keys And Env

Use the app's REST API key as:

```env
AUTH_KAKAO_ID=...
```

If Kakao Login client secret is enabled, copy it as:

```env
AUTH_KAKAO_SECRET=...
```

Keep the secret enabled in Kakao Developers and in production env. Do not commit
real key values.

## Common Rejections

| Rejection                            | Fix                                                                                     |
| ------------------------------------ | --------------------------------------------------------------------------------------- |
| Redirect URI mismatch                | Use the exact Kakao row from `callbacks.md`.                                            |
| App asks for too much data           | Request only `account_email` and `profile_nickname`.                                    |
| Missing privacy disclosure           | Confirm `/privacy` mentions Kakao email/nickname collection and Kakao Corp. processing. |
| Screenshot does not show Kakao Login | Re-run `BASE_URL=https://hideawayseoul.com pnpm oauth:approval:report`.                 |
