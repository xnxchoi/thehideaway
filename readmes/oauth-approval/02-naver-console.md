# Naver Login — Console Submission

Values come from `form-filled.md`. Exact redirect URI comes from
`callbacks.md`, generated by `pnpm oauth:approval:report`.

Console: <https://developers.naver.com/apps/>

Naver review is manual. Submit only after production HTTPS is reachable and the
production sign-in screenshot shows the Naver button.

## Phase 1 — Application

Path: **Application -> 애플리케이션 등록**

- [ ] 애플리케이션 이름: `하이드어웨이`.
- [ ] 사용 API: select `네이버 로그인` only.

Permitted info:

- [ ] 이메일 주소
- [ ] 이름

Leave these unchecked:

- [ ] 별명
- [ ] 프로필 사진
- [ ] 성별
- [ ] 생일
- [ ] 연령대
- [ ] 휴대전화번호

Environment:

- [ ] 서비스 환경: `PC웹`.
- [ ] 서비스 URL: `https://hideawayseoul.com`.
- [ ] Callback URL: paste the Naver `redirect_uri` from `callbacks.md`.

Expected production shape:

```text
https://hideawayseoul.com/api/auth/oauth2/callback/naver
```

Then copy:

- [ ] Client ID -> `AUTH_NAVER_ID`.
- [ ] Client Secret -> `AUTH_NAVER_SECRET`.

## Phase 2 — Review Request

Path: **내 애플리케이션 -> 검수 상태 -> 검수 요청**

Service description:

```text
에디토리얼 에세이와 큐레이션 컬렉션을 제공하는 멤버십 기반 읽기 플랫폼입니다. 사용자는 글을 읽고, 하이라이트와 메모를 남기며, 자신만의 리스트를 구성할 수 있습니다.
```

Naver Login use case:

```text
회원가입 및 로그인을 간소화하기 위해 네이버 아이디로 로그인을 사용합니다. 사용자의 이메일과 이름만 수집합니다.
```

Attachment:

- [ ] Upload `screenshots/01-sign-in-page-prod.png`.
- [ ] Confirm the browser URL in the screenshot is `https://hideawayseoul.com/sign-in`.
- [ ] Confirm Google, Naver, Kakao, passkey, and email/password options are
      visible enough for review.

## Phase 3 — Smoke Test

After approval:

- [ ] Open a fresh browser at `https://hideawayseoul.com/sign-in`.
- [ ] Click Naver.
- [ ] Confirm app name `하이드어웨이`.
- [ ] Confirm only email and name are requested.
- [ ] Complete login and confirm the user lands back authenticated.

## Common Rejections

| Rejection                | Fix                                                                               |
| ------------------------ | --------------------------------------------------------------------------------- |
| Login button not visible | Re-run `pnpm oauth:approval:report` and attach the production sign-in screenshot. |
| Service URL inaccessible | Wait for DNS/TLS/deploy to be green before submitting.                            |
| Excessive user info      | Leave all optional fields unchecked except email and name.                        |
| Redirect URI mismatch    | Use the exact Naver row from `callbacks.md`.                                      |
