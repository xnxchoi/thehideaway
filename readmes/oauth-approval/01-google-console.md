# Google OAuth — Console Submission

Values come from `form-filled.md`. Exact redirect URI comes from
`callbacks.md`, generated by `pnpm oauth:approval:report`.

Console: <https://console.cloud.google.com/>

## Phase 1 — Project

- [ ] Sign in with the Google Cloud account that owns The Hideaway project.
- [ ] Create or open project `The Hideaway`.
- [ ] Confirm the project is selected before changing OAuth settings.

## Phase 2 — OAuth Consent Screen

Path: **APIs & Services -> OAuth consent screen**

- [ ] User type: `External`.
- [ ] App name: `The Hideaway`.
- [ ] User support email: `concierge@hideawayseoul.com`.
- [ ] App logo: optional. If uploading, use `public/android-chrome-512x512.png`
      or another square PNG under 1 MB.
- [ ] Home page: `https://hideawayseoul.com`.
- [ ] Privacy policy: `https://hideawayseoul.com/privacy`.
- [ ] Terms of service: `https://hideawayseoul.com/terms`.
- [ ] Authorized domain: `hideawayseoul.com`.
- [ ] Developer contact email: `concierge@hideawayseoul.com`.

Scopes:

- [ ] `openid`
- [ ] `.../auth/userinfo.email`
- [ ] `.../auth/userinfo.profile`

Do not add Gmail, Drive, Calendar, contacts, or other sensitive/restricted
scopes.

## Phase 3 — OAuth Client

Path: **APIs & Services -> Credentials -> Create credentials -> OAuth client ID**

- [ ] Application type: `Web application`.
- [ ] Name: `The Hideaway — Web`.
- [ ] Authorized JavaScript origins:

```text
https://hideawayseoul.com
```

- [ ] Authorized redirect URIs: paste the Google `redirect_uri` from
      `callbacks.md`.

- [ ] Copy Client ID to `GOOGLE_CLIENT_ID`.
- [ ] Copy Client Secret to `GOOGLE_CLIENT_SECRET`.

## Phase 4 — Publish

- [ ] Publish app after scopes and domains are saved.
- [ ] If Google asks for verification, re-check the scope list. Basic
      `openid`, email, and profile should not require restricted-scope review.

## Phase 5 — Smoke Test

After deploy and env update:

- [ ] Open a fresh browser at `https://hideawayseoul.com/sign-in`.
- [ ] Click Google.
- [ ] Confirm consent screen shows app name `The Hideaway`.
- [ ] Confirm privacy and terms links resolve.
- [ ] Confirm only email/profile permissions are requested.
- [ ] Complete login once approval is live.
